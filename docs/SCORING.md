# Symbol-component scoring

The key was confirmed by the authors after correction of an earlier analysis mapping. Categories describe the intended contrasts; they are not reassigned based on linguistic plausibility.

| Exercise | Visually similar component | Specular/orientation component |
| --- | --- | --- |
| 1 | ∈ versus e | ∞ versus 8 |
| 2 | Σ read as summation versus sigma | ∀ versus A |
| 3 | ∅ versus zero | ∩ versus union |
| 4 | → read as mapping versus tending | ⊆ versus includes |
| 5 | ⟺ versus a one-way conditional | ≤ versus greater than or equal |
| 6 | √ read as square root versus cube root | ] versus [ |
| 7 | vertical bar read as “such that” versus literal bar/absolute value | ∃ versus E |
| 8 | ⇒ read as implication versus “only if” | ∝ versus alpha |

The scoring key assigns scores to every complete response option, including semantically incorrect alternatives. For Exercise 7, “Non esiste” is an incorrect rendering of ∃; an option containing “tale che” can still have the other component correct.

For Exercise 1, the option ending in “più infinito” has the infinity component correct even though the sign is wrong. It remains wrong at the whole-answer level. This was explicitly confirmed by the authors. Therefore component scoring should not be used to reconstruct whole-answer accuracy by multiplying the two component scores. Whole-answer accuracy comes from its own key column.

The component analysis is an exploratory comparison using two scores derived from each original answer; the response-level random intercept accounts for their dependence. Variation in additional errors and distractor structure across exercises should be considered when interpreting the contrast as a mechanism test.
